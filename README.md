# Rufus for Linux

> **Legacy reference:** This repository preserves the earlier Lufus prototype.
> Active native Qt6 Linux development is in the
> [Rufus fork](https://github.com/mcirsta/rufus/tree/codex/linux-qt6-reporting/linux),
> with [Linux preview downloads](https://github.com/mcirsta/rufus/releases).
> The build notes below are historical and do not describe the current port.

An effort to bring Pete Batard's Rufus to Linux

![alt text](http://i.imgur.com/QeBfuuh.png "Logo Title Text 1")

## It is still a work in progress! Not guaranteed to work, at all!

###How to build:

* Git clone or download zip
* qmake
* make

No install so far possible. To test, run the resulting executable.

###Dependencies:

* Qt5
* libparted
